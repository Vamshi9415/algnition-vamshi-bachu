## Leakage Checklist

> Any feature derived from a future value of the target is a data leak.

| Feature | Leakage Risk | Status |
|---------|-------------|--------|
| `revenue_lag1` | Requires t-1 | ✅ Safe (shifted) |
| `revenue_roll_mean_7d` | Requires t-1 to t-7 | ✅ Safe (shift(1) before rolling) |
| `roas` | Requires revenue & spend at same time | ⚠️ Excluded from future rows |
| `conversions` | Unknown at forecast time | ⚠️ Set to 0 in future rows |
| `ctr`, `cpc`, `cpa` | Derived from actuals | ⚠️ Set to rolling mean in future rows |
